A Jetpack Compose + Google Maps project that lets you draw plots by tapping at least 3 points, save them locally using Room, and view them again with camera animation.

## 🧩 Tech Stack
- Kotlin + Jetpack Compose (Material 3)
- Google Maps Compose
- Room Database
- Dagger Hilt for dependency injection
- MVVM architecture

## 🚀 Features
- Tap on map to add 3 or more points to form a polygon.
- Save polygon locally with a custom name.
- View all saved plots in dropdown list.
- Animate camera to the selected plot.
- Store data locally (Room) with reactive updates (Flow).

## 🛠 Setup
1. Add your Google Maps API key in `local.properties` or `AndroidManifest.xml`.
2. Build & run the app from Android Studio.
3. Tap on the map to draw a polygon, press 'Save' to store locally.
